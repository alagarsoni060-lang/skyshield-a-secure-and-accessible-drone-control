# 🛡️ SkyShield – Secure & Accessible Drone Control

## 🚨 Problem Statement

Drones rely on wireless communication and control signals, which can be vulnerable to unauthorized access, command manipulation, and spoofing attacks.

## 💡 Our Solution

**SkyShield** is a secure drone-control prototype designed to provide:

- 🔐 Drone authentication
- 🛡️ Command verification
- 🚨 Spoofing detection
- 📡 Secure communication concept
- 🎮 Accessible drone control dashboard
- ⚠️ Security alerts

## ⚙️ How It Works

User
↓
Authentication
↓
Command Verification
↓
Spoof Detection
↓
Drone Control

## 🚀 Key Features

### 1. Drone Authentication
Only an authenticated user should be able to issue control commands.

### 2. Spoofing Detection
The system checks whether suspicious or unauthorized control activity is detected.

### 3. Secure Control
Commands can be verified before they are accepted by the drone.

### 4. Monitoring Dashboard
The frontend provides a simple interface to monitor drone status and security.
